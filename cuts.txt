7. SIGNAL REGIONS (same in NEW and OLD)
---------------------------------------
  Both regions require trigger + Z candidate + MET cut of the channel (section 5).
  Z_jet   leading selected AK8 jet: pT >= 200 GeV, |eta| < 2.5, msoftdrop > 40 GeV
  Z_bjet  first (highest-pT) selected AK8 jet with PNet >= loose WP, and that jet
          pT >= 200 GeV, |eta| < 2.5; no msoftdrop cut.
          Z_bjet is NOT a subset of Z_jet (tagged jet need not be the leading jet,
          and there is no msoftdrop cut).
  PNet    = particleNetMD_Xbb / (particleNetMD_Xbb + particleNetMD_QCD)  (-1 if denominator is 0)
  Loose WP (OLD inputParameters.txt jet_PNETL_*; same values in NEW):
          2016preVFP 0.9088 | 2016postVFP 0.9137 | 2017 0.9105 | 2018 0.9172

10. INPUT DIFFERENCES (not cuts, but they affect the comparison)
----------------------------------------------------------------
  NEW builds its file lists from OLD FileLists_NanoUL (make_qcd_sf_fileset.py), except:
  - 2016postVFP TTToSemiLeptonic: OLD's list is byte-identical to the preVFP list (bug).
    NEW uses the real postVFP dataset from DAS (138 files).                   <-- DIFF
  - 2016preVFP TTTo2L2Nu: OLD config.ini uses the postVFP dilepton file for preVFP (bug).
    NEW uses the preVFP sample.                                                <-- DIFF
  Data events processed (OLD Nevt vs NEW, same file lists; NEW processed every file):
    2016postVFP SingleElectron: OLD 277.2M vs NEW 291.2M (OLD missing 4.8%)
    smaller OLD shortfalls: 2016preVFP SingleElectron 0.8%, 2016postVFP SingleMuon 0.6%,
    2017 SingleMuon 0.5%, 2016preVFP SingleMuon 0.3%, 2018 EGamma 0.3%;
    2017 SingleElectron and 2018 SingleMuon identical.


11. SUMMARY OF DIFFERENCES THAT CAN CHANGE YIELDS
-------------------------------------------------
  1. Rochester muon corrections: OLD yes, NEW no (-0.2% seen at the two-muon step, 2018).
  2. AK8 jet ID: OLD reads the AK4 Jet_jetId with the FatJet index (bug), NEW uses
     FatJet_jetId. Likely cause of the ~1-1.5% NEW excess at the jet step (same in data
     and MC); not proven.
  3. Top pT reweighting enters NEW's ttbar sumw only: NEW ttbar ~1.1% high.
  4. 2016 ttbar input-file bugs in OLD (section 10).
  5. OLD did not process all data files (section 10).
  Everything else in sections 1-9 is the same.

  Not a yield difference, only plots: OLD fills subjet eta into phi_sub0 and phi into
  eta_sub0 (swapped, Plots.cxx), and uses the leading jet's subjets in Z_bjet; NEW fills
  the correct quantities for the region's jet.

  Cut-boundary conventions differ in a few places (e.g. OLD keeps pT >= 25, NEW pT > 25;
  OLD keeps |dz| <= 0.1, NEW |dz| < 0.1; OLD muon iso <= 0.15, NEW < 0.15). These only
  matter for values exactly on the boundary.
